REQUIREMENTS:
    -Python installed on host machine (device running this program)
    -Host machine turned on and running

    -

AWESOME PROGRAM:
This program is amazing for file streaming (sharing files between device on your local network), and it works without internet while avoiding interference with other servers around the world.

HOW TO USE:
    -Run server.py with the python or py command depending on your python version (3.13 is preferred)
    -Put folders you want to share in the empty /shared directory
    -Look at the output and make sure everything is running correctly (You should be able to see an IP address (192.168.x.x))
    -On a different computer, you can view the hosted website at 192.168.x.x:PORT (the PORT variable in server.py)
